TROUBLESHOOTING GUIDE

No IP address: check Wi-Fi, Ethernet and DHCP.

Websites fail to load: investigate DNS and connectivity.

High latency: check signal strength and network congestion.

Gateway unavailable: check your local network and router.

Four stages of a web connection

01 · DNS

Resolve a domain name to an IP address.

02 · CONNECTION

Establish the required network and secure connection.

03 · REQUEST

The browser requests content from the server.

04 · RESPONSE

The server returns data for the browser to display.
