Networking knowledge base

Core concepts in small, visual lessons
LEARN
⌕

DNS — the internet's address book

DNS helps translate a domain such as example.com into records that tell a device where a service can be found. DNS is not the website itself.

⇄

Routers and routes

A router forwards packets between networks using routing information. Your home router often connects your local network to your internet provider.

▤

Packets

Network data is carried in packets or other protocol units. Each layer adds information needed to deliver data to the right service or device.

⚙

Ports and protocols

Protocols define communication rules. TCP provides a reliable byte stream; UDP sends datagrams without TCP's delivery guarantees. Ports help identify services.

🔒

HTTPS and encryption

HTTPS uses TLS to protect data in transit and help authenticate the server. It does not automatically mean a site is honest or safe to use.

⌁

Latency and bandwidth

Latency is delay; bandwidth is a link's capacity. A connection can have high bandwidth and still feel slow if latency, congestion, or packet loss is high.

Cybersecurity basics

Defensive habits for safer systems and networks
DEFENSIVE LEARNING
Keep software updated

Updates fix known security weaknesses. Use official update channels and restart when needed.

Use unique passwords

Use long, unique passwords and a trusted password manager where possible. Turn on multifactor authentication.

Check links carefully

Look at the actual domain before signing in. Be cautious with unexpected attachments, urgency, and requests for verification codes.

Secure your Wi-Fi

Use modern router security such as WPA2-AES or WPA3, change default admin credentials, and keep router firmware updated.

Least privilege

Use only the permissions needed for a task. Avoid running tools as administrator or root without a clear reason.

Practice with permission

Test only systems you own or have explicit permission to assess. Use a local lab or training platform for security experiments.

This section is for awareness and defense. It does not perform security scans or test the visitor's device.
